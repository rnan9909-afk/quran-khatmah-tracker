# تطبيق ختمتي — متابعة الورد القرآني

تطبيق أندرويد لمتابعة الورد القرآني وإدارة الختمات، بواجهة عربية داكنة عصرية.

## المزايا

- **ختمات متعددة** مع تاريخ بداية لكل ختمة وتتبّع الصفحة الحالية.
- **الهدف اليومي والأسبوعي** داخل مربّعات زجاجية مع أشرطة تقدّم.
- **أين يُفترض أن تكون الآن**: يحسب الصفحة/السورة المستهدفة اليوم حسب خطتك، ويخبرك إن كنت متأخراً/على الخطة/متقدماً.
- **تسجيل سريع** (+1، +5، +10، +20) وأزرار زيادة/إنقاص الصفحة.
- **منتقي السورة والآية** بتصميم عصري، يعرض فقط آيات وسور الصفحة الحالية (يدعم الصفحات متعددة السور).
- **التعويض الأسبوعي**: تعويض يوم فائت مرة كل أسبوع (يصبح اليوم أخضر ويحافظ على التتابع، ويتضاعف هدف يوم التعويض).
- **تقويم حراري وشهري** مع تلوين الأيام حسب تحقيق الهدف.
- **التقرير الأسبوعي** ومقارنة بالأسبوع الماضي، و**رسم بياني** للقراءة اليومية.
- **شريط تقدّم الأجزاء الـ30** و**أوسمة إنجاز**.
- **ودجت على الشاشة الرئيسية** يعرض التقدّم دون فتح التطبيق.
- **زر القرآن العائم**: يفتح تطبيق قرآن خارجي ويظهر زر عودة عائم فوقه.
- **تذكير يومي** ونسخ احتياطي (تصدير/استيراد JSON).
- **التحديث التلقائي داخل التطبيق**: يتحقق من وجود إصدار جديد ويعرض رسالة، ثم ينزّل الـ APK ويثبّته.

## البنية التقنية

- تطبيق أندرويد أصلي (Java) يعرض واجهة ويب (WebView) من `app/src/main/assets`.
- الواجهة: `index.html` + `app.js` + `style.css`، وبيانات صفحات المصحف في `quran_pages.js`.
- الكود الأصلي: `MainActivity`، `SplashActivity`، `NotificationReceiver`، `FloatingButtonService`، `QuranProgressWidget`.

## البناء

يتطلب Android SDK (compileSdk 35) وJDK 21.

```bash
gradle assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`

> ملاحظة: أنشئ ملف `local.properties` وضع فيه مسار الـ SDK، مثال:
> `sdk.dir=C:\\Users\\<اسمك>\\AppData\\Local\\Android\\Sdk`

## نظام التحديث داخل التطبيق

التطبيق يُوزَّع خارج متجر Play، لذا يتحقق بنفسه من التحديثات عبر ملف `update.json` مستضاف على GitHub.

### الإعداد

الرابط مضبوط في [`UpdateManager.java`](app/src/main/java/com/quran/tracker/UpdateManager.java) على:

```
https://raw.githubusercontent.com/rnan9909-afk/quran-khatmah-tracker/main/update.json
```

يشترط أن يكون المستودع **عاماً (public)** وأن يحتوي على ملف `update.json` في جذر الفرع `main`.

### عند إصدار تحديث جديد

1. ارفع `versionCode` و`versionName` في [`app/build.gradle`](app/build.gradle) (مثال: 30 و«4.9»).
2. ابنِ الـ APK: `gradle assembleDebug` — **مهم**: وقّعه بنفس مفتاح `debug.keystore` الموجود في المستودع،
   وإلا رفض أندرويد التحديث فوق النسخة المثبتة.
3. أنشئ Release جديداً على GitHub (مثلاً وسم `v4.9`) وارفع فيه ملف الـ APK.
4. عدّل `update.json` في جذر المستودع (فرع `main`) بالقيم الجديدة وارفعه:

```json
{
  "versionCode": 30,
  "versionName": "4.9",
  "apkUrl": "https://github.com/rnan9909-afk/quran-khatmah-tracker/releases/download/v4.9/khatmati-4.9.apk",
  "notes": "• إضافة كذا\n• إصلاح كذا",
  "mandatory": false
}
```

`mandatory: true` تجعل التحديث إجبارياً (يختفي زر «لاحقاً»).

### ما الذي يحدث عند المستخدم

- عند كل فتح للتطبيق يتحقق بصمت من التحديثات.
- إن وُجد إصدار أحدث تظهر فوراً رسالة «يتوفر تحديث جديد» مع ملاحظات الإصدار، وتتكرر عند كل فتح حتى يتم التثبيت.
- بالضغط على «تحديث الآن» يُنزَّل الـ APK داخل التطبيق مع شريط تقدّم، ثم تُفتح شاشة تثبيت أندرويد.
- أول مرة يطلب أندرويد السماح لتطبيق ختمتي بتثبيت التطبيقات، ثم يتم التثبيت والبيانات محفوظة كما هي.
- يمكن التحقق يدوياً من: الإعدادات ← «التحقق من وجود تحديث».

## التثبيت السريع

يمكنك تثبيت ملف APK الجاهز الموجود في جذر المستودع مباشرةً على الجوال.
